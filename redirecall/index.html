Saved Web Sources

Scheduled Re-crawl

Re-crawls these URLs on a timer so a documentation site stays current without anyone remembering to press Start. The scheduler wakes once a minute and crawls a source when its interval has elapsed; pages that have not changed are skipped, so a re-crawl of an unchanged site is cheap.
Both settings are saved with Save Settings.

Watched Folders

The local-disk twin of scheduled re-crawl: new and changed files (.txt .md .csv .pdf .docx .xlsx) in these folders are ingested into their RAG instance automatically. An edited file replaces its previous version. Files deleted from disk stay indexed — remove them via Documents.

Base Instruction

Applied to every message, before any template. Global rules live here — answer style, and which visual block to use for charts, diagrams, maps and formulas. Leave blank to disable.

🎨 Include chart/diagram authoring rules

On: the assistant can render charts, plots, diagrams, maps, molecules and music (adds ~2,000 tokens to every message). Off: text-only answers with no visual blocks — saves those tokens on every message.

Prompt Templates

Each template is added on top of the Base Instruction when selected from the 💬 menu next to the message box.

Security
RediRecall has no built-in authentication. The fields below are stored in your config but are not enforced — nothing on /api/* or /ws/* checks them, so setting a password here does not protect this instance. To restrict access, put a reverse proxy with authentication in front of it — see deploy/docker-compose.https.yml for a Caddy + HTTPS starting point.
